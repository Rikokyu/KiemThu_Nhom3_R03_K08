# Log evidence

Lưu log đã rà soát và làm sạch tại đây; report tổng hợp đặt trong `reports/`. Mỗi log cần run ID, ngày chạy, công cụ/phiên bản, target local và test case liên quan.

Không commit log thô có password, token, cookie/session, dữ liệu cá nhân, thông tin môi trường nhạy cảm hoặc request/response ngoài scope. Giữ nội dung cần thiết để tái hiện và xác minh; liên kết log từ test case/findings bằng đường dẫn tương đối.
