# Screenshot evidence

Lưu ảnh chụp đã làm sạch tại đây. Dùng tên file gắn với test case/finding và run ID, ví dụ `DAST-01-RUN-01-login-redirect.png`. Ghi chú trong test case hoặc findings cần nêu ảnh chứng minh điều gì và thời điểm chụp.

Trước khi commit, che thông tin tài khoản, dữ liệu cá nhân, token/cookie, hostname/IP không cần thiết và mọi nội dung ngoài scope. Không dùng ảnh chứa secret làm bằng chứng chia sẻ.
